- ⚡ **Event-driven architecture:** Kafka-based services, idempotent consumers, exactly-once thinking in an at-least-once world
- 📡 **Messaging at scale:** MQTT brokers, pub/sub patterns, high-throughput and low-latency delivery
- 🏦 **Reliable backends for regulated domains:** payments and banking systems where correctness is non-negotiable
- 🔭 **Production readiness:** observability, resilience testing, and systems you can trust at 3 a.m.
- 🌱 **Engineering culture:** code reviews, design docs, and mentoring engineers as they grow
